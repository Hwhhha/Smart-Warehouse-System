# Smart Warehouse Management System

## Overview

The Smart Warehouse Management System is a software-based inventory management application developed using Python, Streamlit, and Pandas. It helps warehouse operators track inventory, monitor stock levels, manage items, generate alerts, and visualize warehouse data through an interactive dashboard.

## Features

* Add new inventory items
* Update stock quantities
* Delete inventory items
* Search inventory records
* Low stock alert system
* Inventory dashboard with KPIs
* Download inventory reports in CSV format
* Stock quantity visualization using charts

## Technologies Used

* Python
* Streamlit
* Pandas
* CSV File Storage

## Installation

1. Clone or download the project.
2. Install required libraries:

pip install -r requirements.txt

3. Run the application:

streamlit run app.py

## Problem Solved

Traditional inventory management often relies on manual records, which can lead to stock shortages, data errors, and delayed reporting. This system provides a centralized and automated solution for inventory monitoring and management.
